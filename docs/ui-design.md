# 解压软件 · 界面设计规格（UI Design Spec）

状态：设计已确认，待实现。
依据：`docs/ui.md`（视觉方向）+ 本次设计会话的决策。框架决策见 `docs/adr/0002-ui-framework-wpf.md`。

## 1. 前提与约束

| 项 | 值 |
| --- | --- |
| 框架 | WPF（`net10.0-windows`），**不迁 WinUI 3** |
| 目标机 | Windows 10 LTSC 2021（build 19044） |
| 主题 | 仅浅色 |

由此确定的三条硬约束：

1. **无系统圆角窗口**（Win11 专属）→ 窗口保持直角，圆角只用在控件与面板上。
2. **无 Mica / 亚克力**（Win11 专属，且 ui.md 本就禁止"玻璃拟态"）。
3. **无 `Segoe Fluent Icons`**（Win11 字体）→ 图标一律**自绘矢量 Path**。

范围：重构现有 4 个窗口（主窗口、新建压缩包、密码库、目标已存在）+ **新增 1 个主题化 `MessageDialog`**（ui.md 禁止老式 Windows Dialog，替换现有 8 处 `MessageBox`）。不新增"设置 / 关于 / 首次启动"页面。

### 2.4 字体

| 令牌 | 值 |
| --- | --- |
| `Font.UI` | `Microsoft YaHei UI, Segoe UI`（中文优先回退） |
| `Font.Size.Body` | `13` |

### 2.5 边框与阴影

- 边框统一 `1px`，颜色用 `Brush.Border` / `Brush.BorderStrong`，禁止粗边框与高对比黑边。
- 阴影**仅**用于弹窗与浮层：blur `12`、opacity `0.12`、depth `2`、颜色 `#000000`。禁止厚重阴影与发光。

## 3. 共用外壳（窗口级）

**自绘标题栏**（`WindowChrome`）：

```
┌──────────────────────────────────────────────┐
│ ▣ 窗口标题                        ─  □  ×    │ ← 高 32
├──────────────────────────────────────────────┤
```

- 左：应用图标（16×16）+ 标题（`Font.Size.Caption`，`TextPrimary`）。
- 右：最小化 / 最大化 / 关闭按钮，每个 `46×32`，圆角 `0`。
  - 悬停：`HoverSurface`；关闭按钮悬停：`Danger` 底 + 白字。
- 主窗口可调整大小、含最大化；子窗口固定尺寸、仅含关闭按钮。
- 窗口直角、`1px` 边框 `Brush.Border`；拖动标题栏移动窗口，双击最大化（仅主窗）。

**焦点与键盘**：所有可交互控件有可见焦点框（`1px` `Brush.Accent` 外框）；`Tab` 顺序按视觉从上到下、从左到右；`Enter` 触发主按钮，`Esc` 关闭对话框。

## 4. 图标

自绘矢量 `Geometry`，统一 **16×16 视口、描边 1.5px、圆头圆角端点**，颜色跟随 `TextSecondary`（激活态 `Accent`）。不使用 Emoji / 彩色 / 拟物图标。

| 图标 | 语义 | 出现位置 |
| --- | --- | --- |
| `Icon.Open` | 打开 | 命令栏 |
| `Icon.Test` | 完整性测试 | 命令栏 |
| `Icon.Extract` | 解压 | 命令栏、主按钮 |
| `Icon.Compress` | 压缩 | 命令栏 |
| `Icon.Key` | 密码库 | 命令栏 |
| `Icon.More` | 更多（溢出） | 命令栏 |
| `Icon.File` / `Icon.Folder` | 文件 / 目录 | 列表行 |
| `Icon.Volume` | 分卷 | 信息条徽标 |
| `Icon.Lock` | 加密 | 信息条徽标、密码库列表 |
| `Icon.Eye` / `Icon.EyeOff` | 显示 / 隐藏密码 | 密码库 |
| `Icon.Plus` / `Icon.Minus` | 添加 / 移除 | 压缩窗口 |
| `Icon.Info` / `Icon.Warning` / `Icon.Error` | 信息 / 警告 / 错误 | MessageDialog |
| `Icon.Inbox` | 空状态 | 主窗口空状态 |
| `Icon.Minimize` / `Icon.Maximize` / `Icon.Restore` / `Icon.Close` | 窗口按钮 | 标题栏 |

## 5. 控件规格

| 控件 | 规格 |
| --- | --- |
| `Button.Primary` | 底 `Accent`、白字、高 32、圆角 4；悬停 `AccentHover`，按下 `AccentPressed` |
| `Button.Secondary` | 底 `Surface`、`1px` `BorderStrong`、`TextPrimary`；悬停 `HoverSurface` |
| `Button.Subtle` | 无底无边，`TextSecondary`；悬停 `HoverSurface` |
| `Button.Danger` | 同 Secondary，文字与边框用 `Danger`；悬停 `DangerHover` 底 + 白字 |
| `Button.Command` | 命令栏用：图标 + 文字、高 32、无底；悬停 `HoverSurface` |
| `TextBox` | 高 32、圆角 4、底 `Surface`、`1px` `BorderStrong`；聚焦边框转 `Accent` |
| `ComboBox` | 同 TextBox 外观，高 32 |
| `CheckBox` | 16×16、圆角 4、勾选底 `Accent` |
| `ListView` | 行高 30；悬停 `HoverSurface`；选中 `SelectedSurface`；单行省略 |
| `ListView` 列头 | 高 32、`TextTertiary`、背景 `Background`、底边 `1px` `Border` |
| `ProgressBar` | 高 6、圆角 3、底 `#E5E5E5`、进度 `Accent` |
| `Badge`（徽标） | 高 20、圆角 4、`1px` 边框 `Border`、`TextSecondary`、`Font.Size.Caption` |

**交互状态**统一：`Hover` / `Active` / `Selected` / `Focus` / `Disabled` 用同一套色与 120ms 过渡；无发光、无缩放动画。

## 6. 窗口设计

### 6.1 主窗口（可调整大小，最小 820×520）

```
┌────────────────────────────────────────────────────────────┐
│ ▣ 解压软件                                        ─  □  ×  │ 标题栏 32
├────────────────────────────────────────────────────────────┤
│ ▤打开   ✓测试   ⤓解压   ⧉压缩              密码库   ⋯      │ 命令栏 44
├────────────────────────────────────────────────────────────┤
│ photos.7z · 7z · 1.2 GB · [3 卷] · [加密]                   │ 信息条 32
├────────────────────────────────────────────────────────────┤
│ ☑ │ 名称              │ 大小   │ 压缩后 │ 类型 │ 修改时间   │ 列头 32
│ ☑ │ 📁 2024/          │        │        │ 目录 │            │
│ ☑ │    📄 a.jpg       │ 3.2 MB │ 3.1 MB │ 文件 │ 2024-05-01 │ 行高 30
│ …                                                          │
├────────────────────────────────────────────────────────────┤
│ 目标 [D:\…\Desktop      ] [浏览]  解压到[同名子文件夹▾]     │ 操作区
│ 覆盖[询问▾]  □解压后删除原包  □分卷边解压边删卷   [ 解压 ]  │
├────────────────────────────────────────────────────────────┤
│ ▓▓▓▓▓▓░░░░ 解压中：a.jpg                        [ 取消 ]    │ 进度区（仅运行时）
├────────────────────────────────────────────────────────────┤
│ 共 128 项 · 已选 12 项            7z.dll: 可用 | rar: 缺失  │ 状态栏 24
└────────────────────────────────────────────────────────────┘
```

- **命令栏**：主要动作 `打开 / 测试 / 解压 / 压缩`（图标+文字，左）；`密码库` 与溢出 `⋯`（右）。未打开压缩包时，`测试 / 解压` 置灰。
- **信息条**：拆分自原 `StatusText`，显示文件名、格式、总大小、卷数徽标、加密徽标。未打开时隐藏。
- **文件列表列**：`☑ / 名称 / 大小 / 压缩后 / 类型 / 修改时间`。数据来自 `ArchiveEntry.Size`、`PackedSize`、`ModifiedTime` —— **无需改 Core**。
- **列头 `☑`**：全选 / 全不选（**取代原工具栏的"全选/全不选"按钮**）。
- **操作区**（常驻）：目标路径 + 浏览 + 解压到 + 覆盖策略 + 两个复选框 + 主按钮「解压」。
- **进度区**：仅运行时出现；显示进度、当前项、取消按钮。完成后收起。
- **状态栏**：条目数 / 已选数 + 引擎可用性（`7z.dll`、`rar.exe`）。

### 6.2 新建压缩包（固定 640×520）

```
┌──────────────────────────────────────────────┐
│ ▣ 新建压缩包                          ─  ×  │
├──────────────────────────────────────────────┤
│ 要压缩的内容        [+文件] [+文件夹] [移除] │
│ ┌──────────────────────────────────────────┐ │
│ │ 📁 D:\…\photos                           │ │
│ └──────────────────────────────────────────┘ │
│ 保存为 [D:\…\archive.7z        ] [浏览]      │
│ ── 参数 ──────────────────────────────────── │
│ 格式[7z▾]      级别[标准▾]                   │
│ 分卷[不拆分▾]  [自定义大小    ]              │
│ 密码[              ]  □ 固实压缩（仅 7z）    │
├──────────────────────────────────────────────┤
│ ▓▓▓▓░░░░ 压缩中…            [取消] [ 压缩 ]  │
└──────────────────────────────────────────────┘
```

- `rar.exe` 缺失时：`RAR` 选项置灰 **+ 行内灰字**「未找到 rar.exe」，**取代原 MessageBox**。
- 参数区用两列标签-控件网格，`参数` 分组标题用 `Font.Size.Caption` + `TextTertiary`。
- 前置校验（无内容 / 无保存路径）改为**行内提示**或 `MessageDialog`，不再用 MessageBox。

### 6.3 密码库（固定 420×400）

```
┌──────────────────────────────────────────────┐
│ ▣ 密码库                              ─  ×  │
├──────────────────────────────────────────────┤
│ 解压加密压缩包时，按下列顺序自动尝试         │
│ ┌──────────────────────────────────────────┐ │
│ │ 🔒 ••••••••                        (👁)  │ │
│ │ 🔒 ••••••••••                      (👁)  │ │
│ └──────────────────────────────────────────┘ │
│ [ 密码输入            ] [添加][更新][删除]   │
├──────────────────────────────────────────────┤
│ DPAPI 加密，绑定当前 Windows 用户    [关闭]  │
└──────────────────────────────────────────────┘
```

- 列表**默认掩码 `••••••`**，行尾眼睛图标按下时临时明文显示。
- 选中行后，下方输入框承载编辑；双击行 = 填入输入框（保留原行为）。
- 「关闭」时保存（保留原行为）。

### 6.4 目标已存在（固定 480×200）

```
┌────────────────────────────────────────────┐
│ ▣ 目标已存在                        ─  ×  │
├────────────────────────────────────────────┤
│  ⚠  目标文件已存在                         │
│     D:\…\2024\a.jpg                        │
│  □ 全部套用                                │
│                    [跳过] [改名] [覆盖]     │
└────────────────────────────────────────────┘
```

- 路径**中间省略**显示，`TextPrimary`；`跳过` 为默认焦点，`覆盖` 用 `Button.Danger`。
- 保留 `全部套用` 复选框与原三种结果语义。

### 6.5 MessageDialog（新增，替换 8 处 MessageBox）

```
┌──────────────────────────────────────┐
│ ▣ 提示                        ─  ×  │
├──────────────────────────────────────┤
│  ⚠  解压有错误                       │
│     3 个文件未能解压。               │
│     [详细信息 ▾]                     │
│                     [确定]           │
└──────────────────────────────────────┘
```

- 四种类型：`Info` / `Warning` / `Error` / `Confirm`（是/否）。
- 图标用自绘 `Icon.Info` / `Warning` / `Error`，颜色分别 `Accent` / `#9D5D00` / `Danger`。
- 长文本折叠进「详细信息」，避免对话框撑爆。

### 6.6 状态设计

| 状态 | 表现 |
| --- | --- |
| 空状态 | 主窗口未打开压缩包：居中 `Icon.Inbox`（48×48，`TextTertiary`）+ 文案「拖入压缩包，或点上方"打开"」 |
| 加载状态 | 列表区居中细进度条；命令栏动作置灰 |
| 进度状态 | 主窗口进度区展开；子窗口进度条 + 状态文字 |
| 错误状态 | `MessageDialog`；可恢复错误不打断整体（沿用逐文件汇总） |

## 7. 工程结构（实现落点）

```
src/UnzipTool.App/
├── Theme/

│   ├── Typography.xaml    # 字体令牌 → TextBlock 样式

│   ├── Controls.xaml      # 控件隐式样式与模板
│   └── WindowChrome.xaml  # 自绘标题栏样式（供各窗口复用）
├── MessageDialog.xaml(.cs) # 新增
├── MainWindow.xaml(.cs)    # 重构
├── CompressWindow.xaml(.cs)# 重构
├── PasswordWindow.xaml(.cs)# 重构
└── OverwritePromptWindow.xaml(.cs) # 重构
```

- `App.xaml` 合并上述 5 个资源字典，`Application.Resources` 不再为空。
- **`UnzipTool.Core` 不改**（本设计只用到 `ArchiveEntry` 已有字段）。

## 8. 行为变更清单（相对当前实现）

| # | 变更 | 原因 |
| --- | --- | --- |
| 1 | 8 处 `MessageBox` → `MessageDialog` | ui.md 禁止老式 Windows Dialog |
| 2 | 密码库默认掩码 + 眼睛图标 | 修掉明文显示密码的缺陷 |
| 3 | 「全选 / 全不选」按钮 → 列表列头全选框 | 现代文件管理器惯例 |
| 4 | 新增列表列「压缩后」「修改时间」 | 数据已有，提升信息量 |
| 5 | 主窗口新增空状态；信息条从状态栏拆出 | ui.md 要求空状态同语言、层级清晰 |
| 6 | 压缩窗口 RAR 缺失提示：MessageBox → 行内灰字 | 减少打断 |

## 9. 明确不做

暗色主题、右键 shell 集成、Mica / 亚克力、系统圆角窗口、设置 / 关于 / 首次启动页面、包内搜索与预览、i18n。
