请将整个软件重构为一种现代、简洁、专业的 Windows 桌面软件 UI 风格。

这是一款 Windows 文件压缩/解压工具。

本次要求重点是“统一视觉风格”，而不是规定具体页面布局或具体功能。

不要预设按钮位置、菜单结构、页面结构或功能排列方式。
请根据软件现有功能自行设计合理的界面。

核心目标：

让整个软件看起来像一款成熟的现代 Windows 11 原生桌面工具。

==================================================
整体风格
==================================================

采用现代 Windows 11 + Fluent Design 风格。

关键词：

Modern
Minimal
Clean
Professional
Lightweight
Elegant
Native Windows
Fluent Design
Desktop Utility

整体气质：

简洁
克制
精致
专业
可靠
高效
易用

不要追求“炫酷”，而是通过细节和秩序体现高级感。

==================================================
视觉基调
==================================================

采用明亮的浅色 UI。

以：

白色
浅灰色
极浅蓝灰色

作为主要背景和 Surface。

使用蓝色作为品牌强调色。

蓝色应该是整个软件最主要的 Accent Color，但不要大面积铺满。

整体颜色控制在少量范围内。

避免视觉上出现过多颜色。

==================================================
Windows 11 气质
==================================================

界面应该具有明显的现代 Windows 桌面应用特征。

参考 Windows 11 Fluent Design 的设计理念：

- 简洁
- 清晰
- 层级分明
- 轻量
- 柔和
- 具有空间感
- 强调内容本身

但不要直接复制 Windows 系统应用。

应该形成属于这个压缩软件自己的视觉识别。

==================================================
布局视觉语言
==================================================

整体布局强调：

秩序
对齐
留白
平衡
呼吸感

不要让界面元素过度拥挤。

不同区域之间应该拥有明确但自然的视觉层级。

使用：

间距
留白
背景层次
细边框

来区分不同区域。

不要依赖大量卡片来划分页面。

==================================================
圆角
==================================================

使用克制的现代圆角。

圆角应该柔和，但不能过度。

整体感觉应该：

现代
自然
精致

避免非常夸张的“大圆角”。

不要让整个界面看起来像移动端 App。

==================================================
边框
==================================================

大量使用非常细、非常浅的边框建立结构。

边框应该：

低调
精细
清晰

不要使用粗边框。

不要使用高对比度黑色边框。

==================================================
阴影
==================================================

使用非常轻微的阴影。

阴影只用于表达：

窗口层级
弹窗层级
浮层层级

不要使用厚重阴影。

不要使用明显的黑色投影。

不要使用发光效果。

==================================================
色彩层级
==================================================

推荐建立以下视觉层级：

Background
↓
Surface
↓
Elevated Surface
↓
Interactive Element
↓
Primary Action

不同层级之间使用非常细微的色差体现。

不要使用强烈色块。

==================================================
字体
==================================================

使用现代 Windows UI 字体。

中文优先考虑：

Microsoft YaHei UI

英文优先考虑：

Segoe UI / Segoe UI Variable

字体应该：

清晰
现代
紧凑
易读

不要使用艺术字体。

不要使用过大的标题。

整体字体应该更接近专业桌面工具，而不是营销网站。

==================================================
文字
==================================================

建立清晰的文字层级。

主要文字：

深色
清晰
具有较高对比度

次要文字：

灰色
降低视觉权重

辅助信息：

更浅的灰色

通过：

字号
字重
颜色
间距

建立层级。

不要单纯依靠加粗来区分所有信息。

==================================================
图标
==================================================

统一采用现代线性图标。

图标应该：

简洁
几何
轻量
统一笔画
统一视觉重量

推荐使用类似：

Fluent UI Icons
Lucide Icons

这样的图标语言。

不要使用：

Emoji
3D 图标
卡通图标
拟物化图标
彩色图标
不同风格图标混用

==================================================
控件
==================================================

所有 UI 控件都应该遵循同一套 Design System。

包括：

按钮
输入框
下拉选择
复选框
单选框
开关
列表
表格
菜单
弹窗
提示
进度条
标签
分页
状态组件

它们应该具有统一的：

字体
高度
圆角
边框
间距
图标
状态反馈

==================================================
交互状态
==================================================

Hover、Active、Selected、Focus、Disabled 等状态必须具有统一视觉语言。

状态变化应该：

明显
自然
克制

不要使用夸张动画。

不要使用发光。

不要使用大幅度缩放。

==================================================
动画
==================================================

整体动画非常克制。

如果需要动画：

使用短暂、自然、平滑的过渡。

重点体现：

响应感
流畅感
层级变化

而不是视觉炫技。

==================================================
弹窗
==================================================

弹窗应该具有现代 Windows 桌面软件气质。

使用：

白色 Surface
细边框
轻微阴影
适度圆角
清晰层级

弹窗与主窗口必须属于同一套 Design System。

不要使用传统老式 Windows Dialog 的视觉。

也不要做成网页 Modal。

==================================================
文件管理器气质
==================================================

由于这是压缩/解压工具，整体应该自然具有现代文件管理器的视觉特征。

强调：

文件
文件夹
路径
列表
状态
操作

整体应该让用户感觉：

“这是一个专业的文件工具。”

而不是：

“这是一个普通网页应用。”

==================================================
信息密度
==================================================

整体保持中等偏低的信息密度。

不要为了显示更多内容而过度压缩间距。

文件类信息可以适当提高密度，但仍然需要保持舒适的行高和点击区域。

普通用户应该能够快速理解界面。

==================================================
高级感
==================================================

不要通过：

渐变
玻璃
霓虹
发光
3D
复杂动画
大面积插画

制造所谓的高级感。

高级感应该来自：

精准对齐
优秀间距
统一字体
统一图标
克制颜色
精致边框
细腻状态
自然层级

==================================================
整体产品感
==================================================

所有界面必须像同一个产品。

无论是：

主界面
压缩
解压
设置
密码管理
测试
进度
错误提示
确认窗口
首次启动
关于页面
空状态
加载状态

都必须使用同一套视觉语言。

不要让不同页面出现明显不同的设计风格。

==================================================
禁止风格
==================================================

禁止：

网页后台管理风格
移动端 App 风格
赛博朋克
霓虹渐变
玻璃拟态
过度渐变
3D UI
拟物化 UI
卡通 UI
游戏化 UI
大量彩色卡片
超大圆角
厚重阴影
复杂背景
夸张动画
Emoji 图标
装饰性插画
过度留白导致功能区显得空洞

==================================================
最终视觉目标
==================================================

最终效果应该接近：

“一款经过精心设计的现代 Windows 11 专业压缩软件”。

整体感觉：

干净但不单调
简洁但不简陋
专业但不复杂
现代但不过度设计
精致但不浮夸

请将以上内容作为整个软件的统一视觉 Design Direction。

不要把这些要求理解为具体页面布局规范。

你需要根据实际功能自由设计页面，
但所有页面必须严格遵循这套视觉语言。
