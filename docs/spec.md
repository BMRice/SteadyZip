# 解压软件 · 规格说明（Spec）

状态：已确认，待实现。本文件记录 `grill-with-docs` 会话中达成的共享理解；术语见 `CONTEXT.md`，引擎选型见 `docs/adr/0001-dual-engine-routing.md`。

## 1. 概述

一个 Windows 桌面压缩/解压工具：既能创建压缩包也能解压。差异化能力集中在解压侧：

1. 解压前对压缩包做完整性测试；
2. 分卷压缩包支持"边解压边删卷"，以最小化解压期间的磁盘占用；
3. 密码库保存多个解压密码，遇到加密包自动按序尝试。

目标：自用优先，但代码结构按"将来可对外发布"的标准写。

## 2. 平台与技术栈

- 平台：Windows 桌面 GUI 应用。
- 技术栈：C# / .NET 8 + WPF。
- 引擎：7z.dll（COM 接口直绑）+ 外部 rar.exe（仅用于创建 RAR）。
- 密码库加密：Windows DPAPI。
- 动工前先做 spike，验证"自定义卷输入流在读尽某卷后能删除该卷"确实成立。

## 3. 支持的格式

- 必选：ZIP（含 `.z01/.z02` 分卷）、7z（含 `.001/.002` 分卷）、RAR（含 `.part1/.part2` 分卷）。
- 可选：tar / tar.gz / tar.bz2。
- 分卷特性承诺覆盖 ZIP / 7z / RAR。

引擎分派（按"压缩包格式 × 操作"）：

| 操作 | ZIP | 7z | RAR | tar.gz |
| --- | --- | --- | --- | --- |
| 创建 | 7z.dll | 7z.dll | rar.exe（需检测到） | 可选 |
| 解压 | 7z.dll | 7z.dll | 7z.dll | 7z.dll |
| 完整性测试 | 7z.dll | 7z.dll | 7z.dll | 7z.dll |

## 4. 核心操作

| 操作 | 说明 |
| --- | --- |
| 解压 | 单文件与分卷；ZIP/7z/RAR 必选，tar.gz 可选 |
| 压缩（创建） | ZIP/7z 用 7z.dll；RAR 用 rar.exe（缺失则置灰） |
| 完整性测试 | 独立"测试"按钮 + 解压前自动先测 |
| 浏览压缩包 | 不解压就列出内容、可勾选部分文件解压 |
| 选择性解压 | 只解压勾选的文件/目录 |

## 5. 三大特殊特性

### 5.1 解压前完整性测试

解压操作默认先对整包做逐文件 CRC 全量测试；测试失败即中止，且绝不删除任何卷。

### 5.2 边解压边删卷

- 可选模式，默认关闭。
- 开启时一次性醒目警告，不逐卷打断。
- 顺序：解出某卷数据 → 永久删除该卷源文件（不进回收站）→ 读下一卷。
- 中途硬件级失败则已删卷不可恢复（由完整性预测试兜底）。

### 5.3 密码库

- 保存多个密码，DPAPI 加密本地存储（绑定当前 Windows 用户）。
- 解压加密包时按保存顺序自动尝试，命中即解压。
- 界面可增/删/改密码。

## 6. 分卷处理

- 自动识别 + 枚举卷集：按扩展名（`.z01…zip`、`.001…`、`.part1.rar`）识别，拖入任意一卷即定位整包；识别不到的罕见命名由用户手动补全。
- 创建分卷：支持，每卷大小手动指定（预置 700MB / 4GB 等）。

## 7. 交互方式

- 拖拽打开 + 打开对话框。
- 批量队列串行处理（一个完成再下一个）。
- 右键菜单 shell 集成：MVP 不做，留作后续。

## 8. 压缩选项

- 格式：ZIP / 7z / RAR（RAR 视 rar.exe 可用性）。
- 压缩级别：仅存 / 最快 / 标准 / 最大。
- 加密：创建时可设密码；ZIP 用 AES-256（弃用 ZipCrypto），7z 用 AES-256。
- 分卷大小：手动指定。
- 固实（solid）压缩：默认关，作为 7z 高级选项。

## 9. 解压选项

- 默认目标 = 解压到"同名子文件夹"；另提供"解压到此处"。
- 覆盖策略 = 遇同名文件时询问，可一键套用到全部；另提供 跳过 / 覆盖 / 自动改名。
- 保留目录结构；保留空目录。
- 单文件（非删卷模式）解压后默认保留原包；提供"解压后删除原压缩包"选项。

## 10. 安全与健壮性

- 路径穿越（zip-slip）防护：拒绝绝对路径 / 盘符 / `..`，强制落在目标目录内。
- 密码库 DPAPI 加密。
- 解压炸弹防护：设置很大的解压总大小上限，超限时警告确认。
- Unicode 文件名、zip64 大文件（>4GB）、大分卷。
- 逐文件错误不中断整体，最后汇总报告。
- 进度显示 + 可取消。

## 11. 非目标（MVP 明确不做）

右键菜单集成、多语言 i18n、压缩包内搜索/预览、损坏包修复、压缩包内文件编辑。
